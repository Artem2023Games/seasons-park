# 🎡 Seasons Park — Night Shift

Игра в жанре point-and-click хоррор. Ночной сторож в заброшенном парке аттракционов.

## 🎮 Как играть
Откройте: https://artem2023games.github.io/seasons-park/

## 🎯 Режимы
- **Сюжетная игра** — 5 ночей + секретная + кастомная
- **Мультиплеер** — до 4 игроков
- **Прогулка по парку** — свободный режим
